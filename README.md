# 📊 Retail Sales Analytics – End-to-End Data Analytics Project

An end-to-end retail sales analytics project built using **Excel, SQL, Python, Machine Learning and Power BI**.

The project transforms raw retail transaction data into actionable business insights through data cleaning, relational database management, exploratory data analysis, customer segmentation, inventory analysis and interactive business intelligence dashboards.

---

## 📌 Project Overview

Retail businesses generate large amounts of transactional, customer, product and inventory data. However, raw data alone does not provide meaningful business insights.

This project builds a complete analytics pipeline to:

- Clean and prepare raw retail data
- Store and manage relational data using SQL
- Analyze sales and customer behavior using Python
- Perform RFM analysis and customer segmentation
- Apply Machine Learning clustering techniques
- Analyze inventory and identify low-stock products
- Build interactive Power BI dashboards
- Generate business-focused insights from the data

---

## 🎯 Business Objectives

The main objectives of this project are:

1. Analyze sales performance across stores and staff
2. Identify high-value customers and purchasing patterns
3. Segment customers based on their purchasing behavior
4. Analyze product performance and inventory levels
5. Identify low-stock products
6. Analyze staff performance
7. Track sales trends over time
8. Build an interactive management dashboard
